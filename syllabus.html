על מה הקורסAbout the course

Claude Code הוא סוכן שעובד על המחשב שלכם: הוא קורא את הקבצים שלכם, כותב, מארגן ובונה. הוא לא רק עונה בצ׳אט. בקורס תלמדו להנחות אותו על החומרים שלכם: סילבוסים, סיכומי הרצאות, מאמרים ונתוני מעבדה.

Claude Code is an agent that works on your computer: it reads your files, writes, organizes and builds. It does more than answer in a chat. You will learn to direct it on your own material: syllabi, lecture notes, papers and lab data.

הקורס חזותי: עובדים באפליקציית Claude Desktop ובחלונית של Claude Code בתוך VS Code, ורואים על המסך כל קובץ ש-Claude פותח או משנה. כל מודול נגמר בתוצר שאפשר לפתוח בדפדפן או במסמך. לא צריך ניסיון בתכנות.

The course is visual: you work in the Claude Desktop app and in the Claude Code panel inside VS Code, and you see every file Claude opens or changes. Every module ends with something you can open in a browser or a document. No programming experience is needed.
