Create a Claude account
Free to start

Go to claude.ai
Already have an account? Sign in and confirm your plan includes Claude Code — you'll see it in the sidebar.

WIN
Windows only: Install Node.js first
Windows

The Claude Code extension needs Node.js on Windows. Do this before installing VS Code to avoid the most common setup error.

Download Node.js (LTS)

Click the large LTS button, run the installer, accept all defaults. Then open PowerShell and run:

node --version
You should see v22.x.x — that means it worked.
Done
2
Download the Claude Desktop app

Your companion for managing connections to Google Drive, Gmail, Calendar, and for browsing past sessions and scheduled tasks.

Download Claude Desktop
Mac: If macOS says it can't be opened, go to System Settings → Privacy & Security → click "Open Anyway".
Windows: Sign in with the same Anthropic account you used in Step 1.
Done
3
Install Visual Studio Code

VS Code is the free workspace we'll use for both days. It's where Claude Code lives as a sidebar panel — think of it as your AI-powered office.

Download VS Code

Run the installer and open VS Code once. If you see the welcome screen, you're good.

Done
4
Install the Claude Code extension

This adds the Claude AI panel to VS Code's sidebar. It's the official Anthropic extension — the one we'll use for everything in the course.

  1. In VS Code, press ⌘⇧X (Mac)/ Ctrl+Shift+X to open Extensions
  2. Search for Claude Code
  3. Click Install on the Anthropic extension
  4. Sign in with your Anthropic account when prompted
After installing: Restart VS Code. You should see the Claude icon appear in the left sidebar.
Done
5
Create your course folder

Create a folder on your Desktop called claude-course. Everything you build during the two days lives here — it's your personal Claude workspace.

  1. On your Desktop, create a new folder named claude-course
  2. In VS Code → File → Open Folder → select that folder
  3. Open the Claude Code panel and send this to verify it works:
Can you see any files in this folder?
Expected: Claude says the folder is empty — that's correct and means everything is working.
Done
6
Verify everything works

One last check: open VS Code's terminal and confirm Claude Code is installed at the command line.

Open the terminal in VS Code: press ⌃` or go to View → Terminal. press Ctrl+` or go to View → Terminal.

claude --version
You should see a version number like 1.x.x. If you see "command not found", restart VS Code and try again. Still stuck? Reach out before Day 1!
Done
