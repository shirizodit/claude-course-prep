Windows בלבד: התקינו Node.js קודם Windows only: Install Node.js first
Windows

תוסף Claude Code ל-Windows זקוק ל-Node.js. עשו זאת לפני התקנת VS Code — כדי להימנע מהשגיאה הנפוצה ביותר בהגדרה. The Claude Code extension needs Node.js on Windows. Do this before installing VS Code to avoid the most common setup error.

הורידו Node.js (LTS) Download Node.js (LTS)

לחצו על הכפתור הגדול LTS, הריצו את המתקין, אשרו את הכל. אחר כך פתחו PowerShell והריצו: Click the large LTS button, run the installer, accept all defaults. Then open PowerShell and run:

node --version
תראו v22.x.x — זה אומר שהצליח. You should see v22.x.x — that means it worked.

התקינו את תוסף Claude Code Install the Claude Code extension

זה מוסיף את פאנל Claude AI לסרגל הצד של VS Code. זהו התוסף הרשמי של Anthropic — שנשתמש בו לכל אורך הקורס. This adds the Claude AI panel to VS Code's sidebar. It's the official Anthropic extension — the one we'll use for everything in the course.

  1. ב-VS Code, לחצו ⌘⇧X / Ctrl+Shift+X לפתיחת Extensions In VS Code, press ⌘⇧X / Ctrl+Shift+X to open Extensions
  2. חפשו Claude Code Search for Claude Code
  3. לחצו Install על התוסף של Anthropic Click Install on the Anthropic extension
  4. היכנסו עם חשבון Anthropic כשתתבקשו Sign in with your Anthropic account when prompted
אחרי ההתקנה: הפעילו מחדש את VS Code. תראו את האייקון של Claude מופיע בסרגל הצד השמאלי. After installing: Restart VS Code. You should see the Claude icon appear in the left sidebar.
בוצעDone

צרו את תיקיית הקורס Create your course folder

צרו תיקייה בשולחן העבודה שלכם בשם claude-course. כל מה שתבנו בשני הימים יישמר כאן — זו סביבת ה-Claude האישית שלכם. Create a folder on your Desktop called claude-course. Everything you build during the two days lives here — it's your personal Claude workspace.

  1. צרו תיקייה חדשה בשם claude-course על שולחן העבודה On your Desktop, create a new folder named claude-course
  2. ב-VS Code: File → Open Folder ← בחרו את התיקייה In VS Code → File → Open Folder → select that folder
  3. פתחו את פאנל Claude Code ושלחו כדי לבדוק שהכל עובד: Open the Claude Code panel and send this to verify it works:
Can you see any files in this folder?
תשובה צפויה: Claude אומר שהתיקייה ריקה — זה נכון ומשמעותו שהכל עובד. Expected: Claude says the folder is empty — that's correct and means everything is working.
בוצעDone

בדקו שהכל עובד Verify everything works

בדיקה אחרונה: פתחו את הטרמינל של VS Code ובדקו שה-Claude Code מותקן גם בשורת הפקודה. One last check: open VS Code's terminal and confirm Claude Code is installed at the command line.

פתחו את הטרמינל ב-VS Code: לחצו ⌃` / Ctrl+` או View → Terminal Open the terminal in VS Code: press ⌃`Ctrl+` or go to View → Terminal.

claude --version
אמורים לראות מספר גרסה כמו 1.x.x. אם מופיע "command not found" — הפעילו מחדש את VS Code ונסו שוב. עדיין תקועים? פנו אלינו לפני יום א׳! You should see a version number like 1.x.x. If you see "command not found", restart VS Code and try again. Still stuck? Reach out before Day 1!
